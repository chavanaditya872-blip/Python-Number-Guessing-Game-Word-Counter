# 🎮 Number Guessing Game & Word Counter

## 📌 Project Overview

A beginner-friendly Python command-line application that combines a Number Guessing Game and a Word Counter. This project demonstrates Python fundamentals, including loops, functions, conditional statements, random number generation, file handling, and string manipulation.

## 🚀 Features

### 🎯 Number Guessing Game
- Generates a random number between 1 and 100.
- Allows a maximum of 7 attempts.
- Provides hints (Too High / Too Low).
- Tracks the number of attempts.
- Calculates a score based on performance.
- Handles invalid user inputs.

### 📝 Word Counter
- Reads text from a `.txt` file.
- Counts the total number of words.
- Calculates the number of unique words.
- Analyzes word frequency.
- Displays the 10 most frequently used words.
- Handles missing files and invalid filenames.
